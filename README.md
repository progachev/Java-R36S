# Скрипт установки J2ME для RetroArch на ArkOS

![Java Logo](https://cdn-icons-png.flaticon.com/512/226/226777.png)  
*Автоматическая установка Java 2 Micro Edition (J2ME) для RetroArch*

---

## 📝 Описание

Этот bash-скрипт автоматизирует процесс установки эмуляции Java-игр (J2ME) на устройствах с **ArkOS**. После выполнения:

- Устанавливается полноценная среда для запуска Java-игр
- Добавляется новый раздел в EmulationStation
- Оптимизируются настройки звука и производительности

---

## ⚙️ Технические особенности

- 🔍 **Автодетект расположения** (поддержка двух SD-карт)
- 📂 Установка всех необходимых компонентов:
  - Ядро `freej2me` для RetroArch
  - JDK для ARM64
  - Конфигурационные файлы
- 🛠️ Автоматическая настройка:
  - Добавление системы в `es_systems.cfg`
  - Настройка звука через `asound.conf`
  - Оптимизация CPU (`perfmax/perfnorm`)
- 📜 Подробное логирование всех операций
- 🧹 Автоочистка временных файлов

---

## 📂 Структура установки

```bash
/roms[2]/tools/j2me/
├── Java.sh          # Главный скрипт
└── dep/             # Папка с зависимостями
    ├── freej2me_*   # Файлы ядра
    ├── zulu*.deb    # Пакет JDK
    └── asound.conf # Конфиг звука 
```

## 🚀 Как использовать

    Поместите папку j2me в /roms/tools/ или /roms2/tools/
    Запустите скрипт:
    bash
    chmod +x Java.sh
    ./Java.sh

    После перезагрузки появится раздел J2ME

## 🎮 Особенности работы

    Игры размещаются в /roms[1/2]/j2me/ (формат .jar)
    Автоматическая настройка производительности
    Поддержка управления через RetroArch
    Интеграция с интерфейсом EmulationStation

## ⚠️ Важно

Для корректной работы требуется:

    Подключение к интернету (для первого запуска)

## 📜 Логирование

Скрипт создает подробный лог в формате:
setup_log_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt

## 🔄 Последующие запуски

После установки можно:
    Удалить папку dep
    Добавлять новые игры простым копированием .jar-файлов
    Настраивать параметры через RetroArch
